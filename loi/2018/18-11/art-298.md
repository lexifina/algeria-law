# Art. 298
Les différents établissements publics de santé sont, notamment :
— le centre hospitalo-universitaire ;
— l'établissement hospitalier spécialisé ;
— la circonscription sanitaire ;
— l'établissement d'aide médicale d'urgence.
Les modalités de création, les missions, l'organisation, le fonctionnement ainsi que les critères de classification de ces établissements, sont fixés par voie réglementaire.
