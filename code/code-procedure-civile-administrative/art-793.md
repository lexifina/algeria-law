# Art. 793
En cas de pluralité de saisies sur les biens du même débiteur saisi, devant des juridictions différentes, les deniers doivent être déposés, par les soins de l'huissier ou du commissaire-priseur ou de la personne détenant ces sommes, au greffe du tribunal dans le ressort duquel a été effectuée la première saisie ou la première vente.
