# Art. 388
Si le rejet de la tierce opposition a été statué, le juge peut condamner l'opposant à une amende civile de dix mille dinars (10.000 DA) à vingt mille dinars (20.000 DA) dinars, sans préjudice des réparations civiles qui seraient demandées par les parties.
Dans ce cas, il décide de la non-restitution du montant de la caution.
