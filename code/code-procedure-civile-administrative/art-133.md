# Art. 133
La partie qui entend récuser l'expert désigné est tenue de le faire, dans les huit (8) jours de la notification de cette désignation, par requête contenant les motifs de la récusation et présentée au juge qui a ordonné l'expertise. Il est statué sans délai sur la récusation, par voie d'ordonnance non susceptible de recours.
La récusation n'est admise que pour cause de parenté directe ou collatérale jusqu'au quatrième degré, pour intérêt personnel ou pour autre motif sérieux.
