# Art. 667
Tout créancier, en vertu d'un titre exécutoire, peut effectuer, par ordonnance sur requête rendue par le président du tribunal dans le ressort duquel se trouvent les biens, une saisie-arrêt exécution entre les mains d'un tiers, sur les biens mobiliers corporels, les actions, les parts de bénéfices de société, les bons de caisse ou les créances, même s'ils ne sont pas échus.
