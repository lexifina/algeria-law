# Art. 860
La formation de jugement ou le magistrat rapporteur qui procède à l'audition de témoins peut d'office convoquer ou entendre toute personne dont l'audition lui parait utile.
Il peut également être procédé à l'audition des agents de l'administration ou exiger leur présence pour apporter des éclaircissements.
