# Art. 362
En cas d'indivisibilité à l'égard des parties à l'instance, le pourvoi de l'une d'entre elles produit effet à l'égard des autres, même si elles ne se sont pas pourvues en cassation.
Dans le même cas, le pourvoi formé contre l'une des parties n'est recevable que si toutes les parties sont appelées.
