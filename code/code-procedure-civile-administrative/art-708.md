# Art. 708
La vente par adjudication ne peut avoir lieu qu'après récolement des biens saisis et établissement d'un procès-verbal par l'huissier ou le commissaire-priseur qui mentionne, le cas échéant, les biens manquants.
La vente ne peut avoir lieu que si le nombre des enchérisseurs est supérieur à trois (3) personnes. A défaut la vente est ajournée à une date ultérieure.
