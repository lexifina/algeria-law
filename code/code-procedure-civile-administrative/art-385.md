# Art. 385
La tierce opposition est faite en la forme prévue pour l'introduction des instances. Elle est portée devant la juridiction qui a rendu le jugement, l'arrêt ou l'ordonnance attaqué ; il peut être statué par les mêmes juges.
Aucune tierce opposition n'est recevable si elle n'est pas accompagnée d'une quittance justifiant de la consignation au greffe, d'une somme équivalente au maximum de l'amende prévue à l'article 388 ci-dessous.
