# Art. 619
Si le poursuivi est emprisonné en raison d'un crime ou condamné définitivement en raison d'un délit à une peine égale ou supérieure à deux (2) années d'emprisonnement, et n'a pas de représentant pour l'administration de ses biens, le poursuivant peut faire prononcer en référé une ordonnance portant désignation d'un représentant du poursuivi, parmi les membres de sa famille ou parmi les tiers, pour le représenter lors de l'exécution.
