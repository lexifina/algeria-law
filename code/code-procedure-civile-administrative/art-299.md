# Art. 299
Dans tous les cas d'urgence, ou lorsqu'il s'agit de décider d'une mesure de séquestre ou de toute mesure conservatoire dont la procédure n'est pas réglée par des dispositions spéciales, l'affaire est portée par requête devant le tribunal du lieu de l'incident ou de la mesure sollicitée, et appelée à la plus proche audience.
Les actions en référé doivent être jugées dans les meilleurs délais.
