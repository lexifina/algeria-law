# Art. 411
Le refus de la personne à laquelle est destiné l'acte de signification de le recevoir, de signer le procès-verbal de remise ou d'y apposer son empreinte digitale, est consigné dans le procès-verbal dressé par l'huissier. Une copie de la signification lui est adressée par lettre recommandée avec accusé de réception.
Dans ce cas, la signification est réputée être faite à personne, le délai court à partir de la date du cachet de la poste.
