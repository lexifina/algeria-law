# Art. 733
Si le débiteur saisi ou le détenteur de l'immeuble ou la caution réelle détourne ou cause la détérioration des biens visés à l'article 732 ci-dessus il est passible des peines prévues au code pénal pour les infractions relatives aux objets saisis, sans préjudice des réparations civiles, s'il y a lieu.
