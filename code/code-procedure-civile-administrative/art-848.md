# Art. 848
Lorsque la requête est entachée d'une irrecevabilité susceptible d'être couverte, le tribunal administratif ne peut la rejeter en relevant d'office cette irrecevabilité, qu'après avoir invité son auteur à la régulariser.
L'ordre de régularisation mentionne, qu'à défaut de régularisation, les conclusions pourront être rejetées comme irrecevables dès l'expiration du délai imparti qui, sauf urgence, ne peut être inférieur à quinze (15) jours.
