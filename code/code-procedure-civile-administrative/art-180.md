# Art. 180
L'inscription de faux par voie incidente est formée par conclusions déposées devant le juge saisi de l'action principale. Ces conclusions doivent, sous peine d'irrecevabilité, énoncer avec précision les moyens que la partie invoque pour établir le faux.
Elles doivent être notifiées, à l'autre partie, par les soins de la partie demanderesse à la demande incidente. Le juge fixe les délais qu'il accorde à la partie défenderesse pour répondre à cette demande.
