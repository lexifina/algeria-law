# Art. 650
Tout détenteur d'un droit sur une invention ou un produit enregistré peut opérer saisie conservatoire sur les échantillons de marchandises ou modèles qui ont été contrefaits alors qu'il bénéficient d'une protection légale.
L'huissier dresse un procès-verbal de saisie dans lequel il précise le produit, l'échantillon ou modèle saisi qu'il place sous scellés et le dépose au greffe du tribunal territorialement compétent avec copie du procès-verbal.
