# Art. 77
Quand il y a motif légitime, le juge peut ordonner, avant tout procès, à la demande de toute personne intéressée, toute mesure d'instruction visant à établir ou à consacrer la preuve des faits dont pourrait dépendre l'issue d'un litige.
Le juge ordonne la mesure demandée soit sur requête, soit par voie de référé.
