# Art. 814
Lorsque le tribunal administratif d'appel règle la compétence et renvoie l'affaire devant le tribunal administratif compétent, ce dernier ne peut plus décliner sa compétence.
Lorsque le Conseil d'Etat règle la compétence et renvoie l'affaire devant le tribunal administratif d'appel compétent, ce dernier ne peut plus décliner sa compétence
