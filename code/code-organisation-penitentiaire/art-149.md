# Art. 149
Le dossier de la libération conditionnelle pour cause médicale est formalisé par le juge de l'application des peines sur la base d'un rapport détaillé du médecin de l'établissement pénitentiaire. Il doit comporter un rapport d'expertise médical ou psychiatrique détaillé établi par trois (3) médecins spécialistes requis à cet effet.
