# Art. 39
La juridiction militaire dans le ressort territorial duquel se trouve le lieu de résidence est également compétente, soit pour connaître des infractions commises par des personnes étrangères à l'armée, et libérées de leurs obligations militaires, pour des faits antérieurs, soit pour continuer une procédure antérieurement engagée ou pour purger une opposition, quelle que soit la juridiction précédemment saisie.
Dans le cas où l'auteur réside hors du territoire national, la compétence revient à la juridiction militaire dont l'accès est le plus facile.
