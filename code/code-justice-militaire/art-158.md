# Art. 158
En matière de contravention, le prévenu régulièrement cité à personne, doit comparaître devant le tribunal militaire ; s'il ne comparaît et s'il ne fournit pas une excuse valable reconnue par la juridiction devant laquelle il est appelé à comparaître, il est procédé au jugement lequel est réputé contradictoire.
