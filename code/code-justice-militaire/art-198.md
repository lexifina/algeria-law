# Art. 198
Sont applicables devant la Cour d'appel militaire, les mêmes règles et procédures prévues pour le tribunal militaire. Il est fait application, en outre, des dispositions du code de procédure pénale relatives à la procédure devant la Cour relevant de l'ordre judiciaire ordinaire, en matière d'appel, sous réserve des dispositions du présent code.
