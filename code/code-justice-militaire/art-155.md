# Art. 155
Sans préjudice des peines plus sévères prévues par le code pénal, quiconque se rend coupable envers le tribunal ou envers l'un de ses membres de voie de fait, d'outrages ou de menaces par propos ou geste, est puni, selon le cas, des peines prévues par les articles 334 (alinéa 1er) ou 337 (alinéa 1er) du présent code.
