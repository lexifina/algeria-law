# Art. 285
La peine d'emprisonnement est de cinq (5) ans à dix (10) ans contre tout militaire qui a déserté à l'étranger dans l'une des circonstances suivantes :
1- si le coupable a emporté une arme ou du matériel de l'Etat ;
2- s'il a déserté en étant de service ;
3- s'il a déserté avec complot.
Si le coupable est officier, il est puni de dix (10) ans de réclusion criminelle à temps.
