# Art. 44
Lorsqu'un subordonné est poursuivi comme auteur principal d'une des infractions prévues à l'article 43 ci-dessus, et que ses supérieurs hiérarchiques ne peuvent être poursuivis comme coauteurs, ces derniers sont considérés comme complices dans la mesure où ils ont toléré les agissements criminels de leur subordonné.
