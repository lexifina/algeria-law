# Art. 119
En cas de commission d'un délit prévu par la présente loi, l'agent qui a constaté l'infraction doit s'empresser de transmettre le procès-verbal de constatation, sous format papier ou électronique, au procureur de la République territorialement compétent. Dans ce cas, il est fait application des dispositions du code de procédure pénale.
