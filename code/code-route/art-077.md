# Art. 77
Les titulaires d'un permis de conduire délivré par un Etat avec lequel l'Algérie a conclu un accord de reconnaissance mutuelle des permis de conduire, résidants en Algérie, peuvent convertir leur permis à un permis de conduire algérien selon les conditions précisées dans l'accord ou, le cas échéant, conformément aux exigences du principe de réciprocité.
