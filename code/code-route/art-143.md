# Art. 143
Les peines prévues pour l'infraction commise en état d'ivresse ou sous l'emprise de stupéfiants et/ ou de substances psychotropes, sont applicables au conducteur d'un véhicule ou à l'accompagnateur d'un élève conducteur dans le cadre de l'apprentissage qui refuse de se soumettre à l'éthylomètre et/ou aux examens médicaux et/ou cliniques et/ou biologiques prévus par la présente loi.
