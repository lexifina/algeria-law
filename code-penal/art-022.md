# Art. 22
Le placement judiciaire dans un établissement thérapeutique consiste en la mise sous surveillance dans un établissement approprié par décision d'une juridiction de jugement, d'un individu qui lui est déféré, atteint d'intoxication habituelle causée par l'alcool ou les stupéfiants, lorsque la criminalité de l'intéressé apparait comme liée à cette intoxication.
Ce placement peut être ordonné dans les conditions prévues par l'article 21, alinéa 2.
