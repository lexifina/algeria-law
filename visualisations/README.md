# Le droit algérien en 20 graphiques

[English](README.en.md)

Des graphiques sur le droit de tous les pays, tirés de l’ensemble de global-law : [global-law visualisations/](https://github.com/lexifina/global-law/tree/main/visualisations). Ici figurent uniquement les graphiques sur l’Algérie.

Vingt graphiques sur le droit algérien, tirés uniquement des données de ce dépôt : la Constitution telle que révisée en 2020 et le 26 mars 2026, six codes et 148 lois, lois organiques et ordonnances publiés au Journal officiel de 2002 à 2026, soit 155 textes et 172 versions, chacune datée du jour de son entrée en vigueur et attribuée au texte qui l’a faite. Le texte est celui de l’édition française du Journal officiel ; 148 textes n’y figurent que tels qu’adoptés, et le graphique 17 montre ce que cela veut dire.

Ouvrez [`le-droit-algerien-en-20-graphiques.html`](le-droit-algerien-en-20-graphiques.html) dans un navigateur. La page est un seul fichier qui contient toutes ses données ; elle ne charge du web que la bibliothèque d3 et ses polices. Les boutons en haut à droite choisissent la langue (français ou anglais) et l’affichage (clair ou sombre). Chaque graphique indique sa source dans le dépôt, le nombre d’enregistrements et ses limites, et comporte en dessous un tableau de tous les chiffres. Survolez un élément pour les valeurs exactes.

Les graphiques sont descriptifs : ils montrent ce que les sources enregistrent, pas pourquoi.

## Limites

- **Le dépôt est une sélection.** Il ne contient qu’une partie des lois publiées depuis 2002 (graphique 2), et ni le Code civil, ni le Code de la famille, ni le Code de commerce, ni les lois de finances, ni les décrets, ni la jurisprudence. Les comptes par année disent ce que le dépôt contient, pas l’activité du législateur.
- **« Tel qu’adopté ».** 148 des 155 textes n’ont qu’une version : une modification ultérieure n’y est pas, et un texte abrogé y reste (graphiques 15 à 17). Les comptes de mots, de peines, de délais et de fourchettes lisent ces textes tels qu’adoptés, même abrogés.
- **Les catégories sont lues dans le texte.** Les renvois à la loi, les institutions, les peines, les amendes, les délais et les fourchettes suivent les expressions de `src/prep.py` ; une formulation qu’elles ne reconnaissent pas n’est pas comptée.
- **Les erreurs du dépôt sont signalées, pas corrigées.** La loi n° 02-01 y est datée du 27 avril 1991, avant sa signature ; la loi n° 08-12, qui modifie l’ordonnance n° 03-03 relative à la concurrence, est appliquée à la loi n° 03-03 relative aux zones d’expansion touristique ; les lois n° 04-06 et 04-09 reprennent à leur suite les articles des lois imprimées après elles au Journal officiel (201 fichiers, comptés une fois).
- **Le texte arabe, qui fait foi, n’est pas dans le dépôt** : tout est compté sur l’édition française.
- **2026 est incomplète** (jusqu’au 13 octobre) et dessinée estompée.

## Reconstruire

```sh
python visualisations/src/make.py            # historique, articles et tableaux -> src/.build/ -> le-droit-algerien-en-20-graphiques.html
node visualisations/src/stills.cjs           # les images de ces README (Playwright ; PLAYWRIGHT=<chemin> s’il n’est pas global)
```

`make.py` lit tout dans les objets git : il fonctionne dans un clone sans blobs (`--filter=blob:none`) ou `--no-checkout`, où il télécharge en une fois les quelque 15 000 fichiers d’articles (environ 5 Mo). Il lit `origin/main` (ou `HEAD`) par défaut ; `--ref` choisit une autre branche ou un autre commit. Il n’écrit rien dans le dépôt en dehors de la page et du dossier `src/.build/` (que git ignore).

| Fichier | Rôle |
| --- | --- |
| `src/make.py` | extrait l’historique, les articles de chaque version et les tableaux dans `src/.build/`, puis lance `prep.py` et `build.py` |
| `src/prep.py` | calcule tous les chiffres des 20 graphiques et du profil des données dans `src/.build/data.json` |
| `src/page.tpl.html` | la page : les textes dans les deux langues, les graphiques (d3), les tableaux |
| `src/build.py` | insère `data.json` dans le modèle et écrit la page |
| `src/stills.cjs` | dessine chaque graphique en PNG dans `stills/fr/` et `stills/en/` |
