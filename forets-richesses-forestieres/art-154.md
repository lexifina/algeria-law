# Art. 154
Sous réserve des peines prévues par la présente loi, les sanctions maximales prévues aux articles 136, 137, 139, 141 et 142 cités ci-dessus sont appliquées, si les infractions définies par la présente loi sont commises dans les cas suivants :
— si le contrevenant est un agent public dont la fonction lui facilite la commission de l'infraction ;
— si l'infraction est commise dans les aires protégées ;
— si l'infraction est commise de nuit ;
— si l'infraction est commise par plus d'une personne.
