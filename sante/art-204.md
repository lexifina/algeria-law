# Art. 204
L'inhumation ne peut être effectuée que sur la base d'un certificat médical constatant le décès établi par un médecin selon les modalités fixées par voie réglementaire.
Ce certificat, rédigé sur un modèle établi par l'administration compétente, précise la ou les causes de décès et, éventuellement, les informations utiles pour la santé publique, selon les conditions garantissant sa confidentialité.
