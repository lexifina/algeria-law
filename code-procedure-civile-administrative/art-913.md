# Art. 913
Le sursis à exécution d'une décision rendue par le tribunal administratif peut être ordonné par le Conseil d'Etat si l'exécution de cette décision risque d'exposer l'appelant à une perte certaine irréversible d'une somme d'argent dans le cas où il apparaît que ses moyens d'appel seraient accueillis.
