# Art. 674
Sous peine de nullité de la saisie-arrêt, le procès-verbal de saisie doit être signifié au débiteur saisi, dans les huit (8) jours qui suivent la procédure de saisie-arrêt avec copie de l'ordonnance de saisie. Mention en est faite sur le procès-verbal de signification.
Le créancier saisissant doit élire domicile dans le ressort du tribunal du lieu où se trouvent les biens saisis.
